## 📖 About 

The **Task Manager Tool** is a lightweight and user-friendly application designed to help you manage your daily tasks, projects, and to-do lists. With an intuitive interface and robust functionality, it ensures you never miss a deadline or forget an important task. ⏰

This tool is perfect for:
- 👨‍💻 **Developers** managing project tasks.
- 🎓 **Students** organizing assignments and study schedules.
- 👔 **Professionals** tracking work-related activities.
- 🏠 **Anyone** needing to organize their daily responsibilities.

---

## ✨ Features 

- ➕ **Add Tasks**: Easily add new tasks with descriptions, due dates, and priorities.
- 📝 **Edit Tasks**: Update task details on the fly.
- 🗑️ **Delete Tasks**: Remove completed or unnecessary tasks.
- ✅ **Mark as Complete**: Keep track of your progress by marking tasks as done.
- 🔍 **Search & Filter**: Quickly find tasks using search and filter options.
- 📱 **Responsive Design**: Works seamlessly on desktop devices.

## 🛠️ Installation 

Follow these steps to set up the Task Manager Tool on your local machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Lahirufd/TaskManagerTool.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd TaskManagerTool
   ```

3. **Compile the Java code**:
   ```bash
   javac -d bin src/*.java
   ```

4. **Run the application**:
   ```bash
   java -cp bin TaskManagerApp
   ```

5. 🖥️ The application will launch in a new window on your desktop.

## 🖥️ Usage 

### 📋 Adding a Task
1. Click on the **"Add Task"** button.
2. Fill in the task details (title, description, due date, and priority).
3. Click **"Save"** to add the task to your list.

### ✏️ Editing a Task
1. Click on the **"Edit"** button next to the task you want to modify.
2. Update the task details.
3. Click **"Save"** to apply the changes.

### 🗑️ Deleting a Task
1. Click on the **"Delete"** button next to the task you want to remove.
2. Confirm the deletion when prompted.

### ✓ Marking a Task as Complete
1. Click on the **checkbox** next to the task title.
2. The task will be marked as complete and moved to the "Completed Tasks" section.
